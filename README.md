# ROSIGMA
This repository only host the source for the stable releases of Rosigma, presently version 3.3.

A free submod for 40k OXCE (OpenXcom Extended) made by many contributors over the yeas (see credits in the language file).

Release versions are available to most users via the rosigma mod.io or modDB sites :


https://mod.io/g/openxcom/m/rosigma
or
https://www.moddb.com/mods/rosigma-40k/downloads/rosigma-33-for-40k039-and-oxce87


The latest nightly version is available here : https://codeberg.org/LeflairKunstler/ROSIGMA.

Contributor guidelines and best practices available via our discord : https://discord.gg/qY5V2vYqPM
